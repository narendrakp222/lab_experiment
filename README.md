# Lab Experiments 1–6
| Folder | Contents | How to run |
| --- | --- | --- |
| `Experiment1/` | Your existing HTML/JavaScript exercises | Open HTML files in a browser (use a local web server if a file uses root-relative paths). |
| `Experiment2/React1/` | Runnable React exercises 2(a)–2(e) and 3(a)–3(e) | `cd Experiment2/React1`, `npm install`, `npm run dev`; choose an exercise in the navigation. |
| `Experiment4/` | Git setup, local workflow, branching/conflict guide | Follow its `README.md`. |
| `Experiment5/` | React-to-GitHub and feature-branch/PR guide | Follow its `README.md`. |
| `Experiment6/` | Express routes, CRUD, and MySQL API | `cd Experiment6`, `npm install`, then `npm run 6a` through `npm run 6e`; see its `README.md`. |

**Experiments 2 and 3** each have selectable subexperiments (a–e) in the same React app so no duplicate dependencies are required. The original class counter in `src/App.jsx` runs as 2(a); 2(b) is a functional counter, 2(c) handles a click event, 2(d) toggles its message and 2(e) displays the sample strings. Experiment 3 covers useState counter, useEffect API users (requires internet), props, alert form and mapped student list. Select each labeled button to see its output.

Experiments 4 and 5 require **your** GitHub account, token and repository URL to publish; they are step-by-step exercises, not claims that anything was uploaded. Experiment 6(e) requires a separate running MySQL server and schema import. Experiment 7 was not included in the requested 1–6 range.
